# QF Tool

Personal decision workspace for investing, rewards, deals, side-income opportunities, and investment journaling.

## Data refresh

GitHub Actions refreshes the public dashboard data every day at 8:00 AM in `America/Los_Angeles`. The production site reads that data directly from this repository, and the workflow can also be started manually.

Live site: https://qf-tool.h1nano.chatgpt.site

Private inputs such as wish-list items and journal entries remain in the browser's local storage and are never committed to the repository.
